# 中国法研究

| 技能 | 用途 |
|---|---|
| `cold-start-interview` | 建立非敏感研究画像 |
| `authority-check` | 核验法规、司法解释、案例的版本与引用姿态 |
| `case-comparison` | 类案检索、事实可比性和裁判状态检查 |
| `issue-memo` | 争点驱动的研究备忘录与相反论证 |
| `lecture-source-pack` | 法律讲座的来源包、案例状态及讲前复核 |

`law-change-watch` Agent 只生成变化线索，不自动改客户政策、发送通知或确定期限。连接器及认证边界见根目录 `CONNECTORS.md`。
