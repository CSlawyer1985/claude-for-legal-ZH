# 中国法律能力升级计划（2026-09）

## Goal

把本仓库从通用法务模板扩展为可用于中国律师主要工作流的插件集，并使法律 MCP 的公开配置与供应商现行文档一致。业务材料、个人画像与密钥均不进入仓库。

## Baseline and gaps

- 13 个领域、157 个原始技能、10 个领域 Agent；现有三个检查命令通过。
- 合同、诉讼、尽调、监管已有入口，独立的中国法检索研究与政府采购缺位。
- 12 份 `.mcp.json` 中元典端点混用旧 HTTP 地址与未声明密钥来源的本地进程；三份北大法宝端点与官方当前指南不符。
- 连接器文档把供应商声称、配置存在和实测可调用混作一层；官网数据源与 MCP 服务混列。
- 工作区采用不同案卷结构。公开插件只能提供语义映射，不能携带个人路径或复制客户规则。

## Design and boundary

1. 新增 `legal-research-cn`、`law-practice-cn` 和 `procurement-legal` 三个独立领域，分别承接中国法研究、律师客户服务与政府采购，避免把律所报价放入法学院诊所。
2. 在现有商事合同、公司尽调与诉讼领域新增具体工作流，覆盖建设工程合同、底稿问题矩阵和中立仲裁庭审提纲；另为咨询、报价、一般投诉及法律讲座提供可触发技能。
3. 公开连接器只保留有官方接入文档的端点；默认元典使用统一 HTTP 地址。需自行认证的北大法宝保留为按需配置示例，不提交令牌，不安装外部包。
4. 维护跨端适配层的单一生成源，重新生成 Codex、dsh、WorkBuddy adapter；更新 README 和接入文档中的数量与路由。
5. 新技能遵守来源分层、法律时点、四层分离、程序期限和人工复核。不可把 MCP 检索结果直接当成已核验现行法。

## Acceptance

- 原有发布检查、工具范围 lint 和 cookbook 测试仍通过。
- 新技能前置元数据与插件注册表有效，生成后的三套 adapter 均包含新领域与技能。
- 静态连接器检查确认默认端点、无密钥、无失效端点和文档一致性。
- 新增静态用例检查路由登记及部分边界词；来源状态、敏感材料外传和期限判断仍需后续模型实跑及律师复核。

## Regression and rollback

最可能受影响的是旧元典连接、插件发现及已有技能路由。保留 `yuandian` 名称，连接器修改前做带校验的备份；任何用户侧认证仍由使用者在对应宿主完成。新文件可按 Git diff 逐项撤销，旧内容不批量改写。
