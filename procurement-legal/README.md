# 政府采购与招标投标

| 技能 | 适用场景 |
|---|---|
| `cold-start-interview` | 角色、地区、采购体系与交付画像 |
| `regime-triage` | 政府采购与招投标制度路由 |
| `bid-review` | 采购/招标文件、资格材料和评分规则审查 |
| `challenge-complaint` | 质疑、答复、投诉的争点证据与候选期限 |
| `contract-performance` | 中标后合同、变更、验收与支付风险 |

`notice-watch` Agent 只做公开公告变动和候选期限提醒，不提交文件、不发送通知。法源、限额及程序期限须按具体项目现时核验。
