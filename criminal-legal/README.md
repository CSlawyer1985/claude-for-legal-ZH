# 刑事法律业务 (Criminal Legal)

本目录为法律人工智能体在**刑事辩护与刑事合规**领域的适配层和工作流集合。

刑事案件的办理对律师的逻辑推演、证据审查能力要求极高，同时伴随着极端的保密义务和人身自由风险。因此，本模块被设计为“律师的辅助分析脑”，而非“自动定罪量刑机”。

## 🚨 核心原则：强制脱敏使用
由于大语言模型的使用存在云端数据传输（哪怕是 API），**严禁将未经脱敏的刑事案卷、起诉书、证据材料原件及照片直接输入本系统**。

使用本模块前，必须由人工将案件事实抽象化，或替换所有敏感实体为占位符（如 `[被告人A]`、`[某科技公司]`、`[某省市]`）。

## 📦 提供的技能 (Available Skills)

| 技能名称 | 目录 | 适用场景 |
| :--- | :--- | :--- |
| **阅卷笔录与证据链梳理** | `case-analysis/` | 针对繁杂的供述、证人证言，梳理时间线，提取矛盾点，发现孤证。 |
| **企业刑事合规不起诉审查** | `compliance-non-prosecution/` | 涉案企业合规整改草案评估，梳理盲点，比对最高检合规标准。 |
| **取保候审及羁押必要性审查** | `bail-application/` | 基于法定事由（如疾病、谅解、无社会危险性）提取要点，辅助撰写申请文书框架。 |
| **辩护思路与类案检索** | `defense-strategy/` | 针对抽象案情进行罪与非罪、此罪与彼罪的法理分析，提取争议焦点。 |

## 🚀 如何使用
在使用带有 `/criminal-legal:*` 意图的工作流时，Codex 代理将自动加载 `criminal-legal/CLAUDE.md` 中的高保密设定及专业画像，并根据选择的技能指导输出。
