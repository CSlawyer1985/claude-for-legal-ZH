# 刑事辩护与合规 (criminal-legal)

本目录为刑事辩护与刑事合规领域的适配层和工作流集合。

刑事案件的办理对律师的逻辑推演、证据审查能力要求极高，同时伴随着严格的保密义务和人身自由风险。因此，本模块被设计为"律师的辅助分析脑"，而非"自动定罪量刑机"。

## 🚨 核心原则：强制脱敏使用

由于大语言模型的使用存在云端数据传输（哪怕是 API），**严禁将未经脱敏的刑事案卷、起诉书、证据材料原件及照片直接输入本系统**。

使用本模块前，必须由人工将案件事实抽象化，或替换所有敏感实体为占位符（如 `[嫌疑人A]`、`[某涉案公司]`、`[某市公安局]`）。技能内置脱敏检查，发现疑似未脱敏信息会立即停止并提示。

## 📦 提供的技能

| 技能 | 目录 | 适用场景 |
| :--- | :--- | :--- |
| 阅卷笔录与证据链梳理 | `case-analysis/` | 针对繁杂的供述、证人证言，梳理时间线，提取矛盾点，发现孤证 |
| 取保候审及羁押必要性审查 | `bail-application/` | 基于法定事由提取要点，辅助撰写申请文书框架 |
| 企业刑事合规不起诉审查 | `compliance-non-prosecution/` | 涉案企业合规整改草案评估，梳理盲点，比对合规评估标准 |
| 辩护策略分析 | `defense-strategy/` | 针对脱敏案情进行罪与非罪、此罪与彼罪的法理分析，提取争议焦点 |

另有标准件：`cold-start-interview/`（首次设置）、`customize/`（画像微调）、`matter-workspace/`（多案件工作区隔离）。

## 📚 内置参考库

`references/` 收录刑事诉讼法核心条文（取保候审、逮捕、羁押必要性审查、非法证据排除）与涉案企业合规评估基准，作为输出的防幻觉兜底依据。引用定罪量刑标准、入罪数额界限时仍须通过法律数据库复核时效。

## 🚀 如何使用

首次使用运行 `/criminal-legal:cold-start-interview` 完成执业角色与办案偏好设置。之后以自然语言描述任务即可，例如：

```text
这是脱敏后的三份讯问笔录摘要，帮我交叉对比时间线，找出供述矛盾点。
```

```text
[嫌疑人A]系[某涉案公司]法定代表人，涉嫌虚开增值税专用发票，已被逮捕。提取可以申请羁押必要性审查的事由。
```
