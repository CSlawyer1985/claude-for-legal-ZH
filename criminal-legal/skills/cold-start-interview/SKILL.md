# /cold-start-interview

运行冷启动面谈。首次运行写入 `~/.claude/plugins/config/claude-for-legal-zh/criminal-legal/CLAUDE.md`；
后续运行使用 `--redo` 重新面谈并在覆盖前显示差异。

## 使用说明

1. **检查当前状态：** 读取 `~/.claude/plugins/config/claude-for-legal-zh/criminal-legal/CLAUDE.md`。如含 `[PLACEHOLDER]`，继续全新面谈。如已填充且未传 `--redo`，询问："看起来你已经设置好了。要重新运行面谈吗？这将覆盖配置（我先给你看差异）。"

2. **按以下面谈脚本执行。**

3. **索取实务文件：** 辩护词范本、取保候审申请书范本、合规整改计划范本、团队办案流程说明。接受文件路径或脱敏后的样本。**绝不索取未脱敏的真实卷宗。**

4. **阅读已分享的文件** 并提取实际立场——辩护策略偏好、文书风格、合规业务深度。标注陈述的立场与范本实际体现之间的差异。

5. **迁移：** 如有已填充的 CLAUDE.md（无 `[PLACEHOLDER]` 标记）在 `~/.claude/plugins/cache/claude-for-legal-zh/criminal-legal/*/CLAUDE.md` 但不在配置路径，将其复制至配置路径并展示迁移内容。

6. **写入 `~/.claude/plugins/config/claude-for-legal-zh/criminal-legal/CLAUDE.md`**（按需创建父目录），按模板结构撰写。尽可能使用律师自己的措辞。

7. **展示摘要 + 建议下一步：**
   - "以下是我听到的——配置已写就。我说错了什么？"
   - 提供测试："想拿一个脱敏案情试试辩护策略分析，或测试一下阅卷矛盾点排查吗？"

## `--check-integrations`

重新运行集成可用性检查（法律检索连接器 yuandian/北大法宝/威科、文件存储）并更新配置中的集成状态。不重新面谈。

探测时：仅当 MCP 工具调用实际成功时报告 ✓。已配置但未测试的连接器标记 ⚪ 附确认方法说明。绝不基于 `.mcp.json` 声明报告 ✓。

## 示例

```
/criminal-legal:cold-start-interview
```

```
/criminal-legal:cold-start-interview --redo
```

## 目的

你正首次见到这个刑事业务实务。你的工作是了解*他们*如何做刑事业务——而非抽象的刑事辩护如何做——并将了解到的内容写成一个活的实务画像（插件配置），本插件的每个其他技能在做事前读取它。

律师离开这次对话时应感到如同他们刚培训了一个聪明的、问了恰好正确的问题的新助理。

## 检查共享的公司画像

查找 `~/.claude/plugins/config/claude-for-legal-zh/company-profile.md`。

- **如存在：** 读取。显示一行确认，跳过公司问题——直接进入插件特定问题。
- **如不存在：** 你将是用户设置的第一个插件。提出公司问题（执业类型、律所名称、核心业务、管辖、规模）并写入共享画像，告知用户其他法律插件将读取它并跳过这些问题。

## 面谈脚本

### 第〇部分：角色与执业类型

1. "你的角色是？（执业律师 / 非律师但有律师支持 / 其他）"
2. "你的执业定位最接近哪一个：**辩护律师**（为嫌疑人/被告人辩护）、**企业合规顾问**（涉案企业合规整改）、**控告方代理**（代理被害人/控告人）、还是**兼顾**？"
3. "辩护立场校准：证据不足时是否坚决无罪辩护？事实清楚时主打罪轻还是程序辩护？涉企案件是否优先评估合规不起诉路径？"

### 第一部分：业务画像

4. "你实际办理的刑事案件类型主要有哪些？（经济犯罪/职务犯罪/行政犯/涉企合规/刑事控告……按频率排个序）"
5. "常见办案机关地域是哪里？"（写入核心管辖地）
6. "案件文件怎么存放？原始卷宗与脱敏副本如何分开管理？"

### 第二部分：集成

7. 探测法律检索连接器（yuandian / 北大法宝 / 威科先行 / 聚法案例）可用性，如实记录。
8. "团队内部的汇报/审批规则？（无罪辩护决定、重大敏感案件是否需要团队负责人把关）"

### 收尾

复述摘要 → 确认 → 写入配置 → 建议测试命令。

**全新职业画像。** 设置仅从用户的回答和他们明确分享的文件构建画像。不读取无关对话或个人历史。如当前对话上下文中出现相关内容，使用前先询问。

**脱敏纪律贯穿面谈：** 如用户在面谈中开始讲述真实案件细节（真实姓名、案号），立即提醒："画像只需要你的执业偏好，不需要具体案件信息。请保持概括描述。"
