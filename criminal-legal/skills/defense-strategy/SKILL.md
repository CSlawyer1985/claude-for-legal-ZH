# 辩护策略分析 (Defense Strategy)

刑事辩护的核心在于准确定性与寻找出罪/罪轻的突破口。本技能根据用户提供的脱敏案件事实，通过拆解犯罪构成要件（主客观相统一），分析是否存在阻却违法的抗辩理由。

## 🛡️ 前置检查：绝对脱敏与防伪造案例

1. **强制脱敏检查**。发现真实敏感信息立即停止执行并警告。
2. **禁止虚构指导性案例**：在提供类案参考或罪名辨析时，严禁自行捏造裁判文书。所有类案分析必须要求用户提供来自**北大法宝**、**中国裁判文书网**或**《刑事审判参考》**的真实案例链接或案号，或通过法律检索连接器当场验证。未验证的定罪量刑标准一律标注 `[要求人工在威科/北大法宝复核]`（纪律见 CLAUDE.md「严防法律幻觉」）。

## 📋 工作流程

### 阶段一：犯罪构成要件拆解

基于刑法学原理，分析指控的罪名：
- **客观方面**：是否存在危害行为？因果关系是否成立？（重点分析是否属于正当防卫、紧急避险、意外事件）
- **主观方面**：是故意（直接/间接）还是过失（疏忽大意/过于自信）？是否存在认识错误？
- **主体与客体**：是否达到刑事责任年龄？是否侵犯了该罪名保护的法益？

### 阶段二：罪与非罪、此罪与彼罪的界限辨析

- **罪与非罪**：行为是否属于一般违法行为（如普通民事违约、一般治安违法、经济纠纷），而尚未达到刑法规定的"情节严重"、"数额较大"的定罪标准？是否属于民事欺诈与刑事诈骗的界限争议？
- **此罪与彼罪**：例如，职务侵占罪与挪用资金罪的辨析，抢劫罪与敲诈勒索罪的边界，故意伤害致死与故意杀人罪的区别。

### 阶段三：提出无罪或罪轻的辩护切入点

1. **实体辩护点**：法定从轻、减轻、免除处罚情节（自首、立功、从犯、未遂、中止等）。
2. **程序辩护点**：是否存在非法证据排除线索（管辖违法、刑讯逼供、搜查扣押程序违法——比对 `references/criminal-procedure-core.md` 第2节）。

### 输出格式

```markdown
## 一、 案件核心争议焦点 (Issue)
- 焦点1：...
- 焦点2：...

## 二、 犯罪构成要件分析 (Rule & Application)
| 构成要件 | 控方可能的逻辑 | 辩方的突破口 |
| :--- | :--- | :--- |
| 客观行为 | ... | ... |
| 主观意图 | ... | ... |

## 三、 此罪与彼罪 / 罪与非罪界限辨析
- 分析该案事实为何更倾向于（或可以争取辩护为）较轻的罪名，或者属于一般民事纠纷不构成犯罪。

## 四、 辩护策略建议总览
1. **首选策略**：（例如：打无罪，切入点为不具备非法占有目的）
2. **备用/并行策略**：（例如：打罪轻，主张属于从犯、未遂）
3. **程序提示**：提醒律师查阅某类录音录像或申请调取某项关键书证。
```

**边界**：不提供确定性的定罪量刑结论。论证强度不足的切入点标注 `{论证强度：弱/推测}` 并说明补强方向。输出末尾附加 CLAUDE.md 规定的审查备注、免责声明与下一步决策树。
