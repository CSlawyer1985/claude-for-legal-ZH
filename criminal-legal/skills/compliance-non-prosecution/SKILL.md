# 涉案企业合规不起诉审查 (Compliance Non-Prosecution)

针对涉税、环保、安全生产、数据安全、侵犯知识产权等犯罪，检察机关对涉案企业适用合规考察制度。本技能辅助律师审查企业的合规整改草案，确保其符合第三方监督评估机制的要求。

## 🛡️ 前置检查：绝对脱敏

在开始任何处理之前，执行严格的**脱敏检查**。若发现输入文本中包含真实的涉案企业名称、企业家姓名：
1. 立即停止执行。
2. 回复要求使用占位符（如 [某化工企业]、[法定代表人A]）。

## 📋 工作流程

### 阶段一：涉案犯罪与合规对象匹配

识别企业涉嫌的罪名（如虚开增值税专用发票罪、污染环境罪、侵犯公民个人信息罪）。
明确合规整改的核心对象应当是"引发该犯罪的企业内部管理漏洞"。

### 阶段二：审查合规计划书 (Compliance Plan Review)

以《涉案企业合规建设、评估和审查办法（试行）》（全厅联发〔2022〕13号）为标准（细则见 `references/criminal-compliance-core.md`），审查维度包括：
1. **专项合规 vs 全面合规**：整改计划是否精准对焦涉嫌犯罪的领域（专项），并适当兼顾其他潜在风险？
2. **组织架构**：是否设立了独立运作的合规委员会或合规官？
3. **制度建设**：是否有针对性的规章制度（如涉税风险隔离墙、环评审批前置流程）？
4. **运行机制**：是否包含合规举报渠道、合规绩效考核、违规惩戒措施？
5. **切割机制**：涉案企业与涉案企业家（个人）的责任是否进行了有效切割？

### 阶段三：发现盲点与提出改进建议

列出计划中缺失的"标配"要素（例如很多企业忽略了对第三方供应商的合规审查，或者没有设计举报人的保护机制）。

### 输出格式

```markdown
## 一、 涉案合规基础定性
- **涉嫌罪名**：...
- **合规领域**：...

## 二、 合规计划实质性审查 (差距分析)
| 评估维度 | 当前计划内容 | 存在盲点/不足 | 改进建议 |
| :--- | :--- | :--- | :--- |
| 组织与保障 | ... | ... | ... |
| 风险识别与管控制度 | ... | ... | ... |
| 监督、举报与惩戒机制 | ... | ... | ... |

## 三、 迎检（第三方监督评估）核心提示
针对该类犯罪的第三方检查，通常会着重抽查哪些实质性证据（例如培训记录、
员工访谈、内部审批流截图），提醒企业切忌"纸面合规"。

## 四、 程序提示
- 合规考察的启动节点（审查起诉阶段为主）、考察期限、与认罪认罚的衔接。
- 各地第三方机制管委会评估细则差异 `[需核实]`。
```

输出末尾附加 CLAUDE.md 规定的审查备注、免责声明与下一步决策树。
