# /customize

## 何时运行

用户输入 `/criminal-legal:customize`。他们想修改实务画像中的某项设置——执业角色、辩护立场校准、案件类型表——而不重跑整个冷启动面谈，也不手动编辑配置文件。

## 操作步骤

1. **读取配置。** 读取
   `~/.claude/plugins/config/claude-for-legal-zh/criminal-legal/CLAUDE.md`
   （以及上一层的 `~/.claude/plugins/config/claude-for-legal-zh/company-profile.md`）。如配置不存在或仍含 `[PLACEHOLDER]`，提示：

   > 你还没有运行过设置。请先运行 `/criminal-legal:cold-start-interview`——customize 用于调整已有画像。

2. **展示可修改地图。** 分组列出画像内容，每项一行当前值摘要：

   - **公司/你是谁** — 名称、业务、管辖、规模 *（共享画像——修改写入 `company-profile.md`，全部插件生效）*
   - **执业角色** — 辩护律师 / 企业合规顾问 / 控告方代理 / 兼顾；辩护立场校准
   - **业务画像** — 常见案件类型表、办案机关地域、文件存储方式
   - **输出规范** — 标头、免责声明偏好
   - **集成** — 法律检索连接器状态
   - **事项工作区** — 是否启用多案件隔离

3. **询问修改点。** "想改哪一项？"用户说明后，先复述将要写入的变更，确认后再写入。

4. **写入并确认。** 修改对应文件，展示改动段落。

## 纪律

- 不改用户未要求修改的部分。
- 涉及脱敏红线、防幻觉纪律的"修改"请求（如"关闭脱敏检查"）——拒绝并说明这是保护用户的硬底线，不可配置。
- 修改后提示："其他技能下次运行时即读取新值。"
